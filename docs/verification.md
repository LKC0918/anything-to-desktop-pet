验证日期：2026-11-06。

这份 skill 已用一张透明 PNG 进行独立制作试用，并继续完成原生 macOS 桌面交互实测。以下是脱敏后的结果摘要，不包含本机路径、进程信息或原始运行日志。

## 验证对象与环境

- 对象：保留原图的常驻桌宠，提供点击弹跳、拖动、隐藏、暂停和退出。
- 实现：Swift + AppKit，应用从自身 bundle 读取图片资源。
- 环境：macOS 27.0.1、arm64、单屏。
- 交付物检查：应用构建成功，本机临时签名校验通过；未进行 Apple 公证。
- 本仓库：提供 skill、参考指引、素材工具和示例图片，不包含示例应用二进制。

## 13 项真实 GUI 检查

测试使用真实原生鼠标输入与菜单交互，并核对实际窗口位置、菜单状态、事件和进程结果。全部通过：

1. 打包应用正常启动，显示原图。
2. 将桌宠定位到屏幕顶边。
3. 顶边点击有可见的向下反馈，并回到原位。
4. 未暂停时可拖动到普通位置，释放不触发跳跃。
5. 普通位置点击向上弹跳，并回到原位。
6. 暂停后菜单勾选正确，“跳一下”菜单项禁用。
7. 暂停后点击不产生窗口位移。
8. 暂停状态仍可拖动。
9. 恢复后动作状态正常。
10. 隐藏后可从菜单栏恢复，位置保留。
11. 从菜单退出后进程消失。
12. 独立重新启动后恢复保存的位置。
13. 再次退出后进程消失。

本次修复了顶边点击反馈被边界限制为零的问题，并补充了窗口、角色与菜单栏的辅助功能标识。
